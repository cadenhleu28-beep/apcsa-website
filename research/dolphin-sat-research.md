## How the Short-Form Format Works

### 1. Vertical scrollable feed
- Question library: **10,000+ official Digital SAT questions** (up from 5,000 earlier in 2025).
- Each "post" in the feed is one SAT question — answer choices rendered like a card.
- You **swipe up** to advance, same gesture as TikTok / Reels / Shorts.
- No menus, no dashboards, no syllabus picker — you open the app and immediately start consuming.
- Explicitly designed to feel "manageable" vs. a 500-page prep book: 5 questions in a feed feels achievable.

### 2. Sub-60-second video explanations
- **Every** question has its own short-form video walkthrough.
- Target length: under 60 seconds per explanation.
- Hosted inline — appears in the feed after answering, before swiping to the next question.
- This is the *core* short-form-content mechanic: the explainer itself is a TikTok-length clip, not a wall of text.

### 3. Adaptive feed (the "For You Page" analog)
- Algorithm tracks weak spots **in real time**.
- Built-in **spaced repetition** decides when to resurface a topic.
- Personalized study plan adapts as your score improves — no manual planning.
- Functionally: the feed isn't a fixed sequence, it's an ML-driven recommendation queue, mirroring TikTok's FYP.

### 4. Micro-sessions
- Designed for 20-minute (or shorter) sessions — "on the bus, in line, before bed."
- Daily streak tracking + push reminders to build habit loops (Duolingo-style retention play, fused with TikTok-style consumption).

## Gamification Layer

- **Dolphin Party** (v1.1.4): real-time multiplayer mode — invite friends, race on speed + accuracy for SAT Module 1.
- **Leaderboards** — global and league-based ranking.
- **Streaks** — daily-use stickiness.
- **Friend code referrals** — viral growth loop.

## Support / AI Layer

- **Pip** — built-in AI tutor, trained on thousands of real SAT questions and "professional Desmos solutions." On-demand chat for hints + step-by-step help.
- **Community Discord** — direct access to human tutors.
- **Guided Solutions** — enforce conceptual checkpoints before letting the user move on.
- Integrated **scratchpad + Desmos calculator** mirroring the real Digital SAT testing UI.

## Key Mechanics That Make It "Short-Form"

| Mechanic | TikTok analog | Studying analog |
|---|---|---|
| Vertical swipe feed | FYP scroll | Question deck |
| Sub-60s video per item | Short-form video | Explainer |
| Algorithmic ranking | FYP recommender | Spaced-repetition + weakness model |
| Streaks | Daily login | Habit loop |
| Friend challenges | Duets / stitches | Dolphin Party multiplayer |
| Leaderboards | Creator rankings | Score competition |
| No menus / instant-on | Open → scroll | Open → answer |

The core insight: **break each unit of study into a single swipeable card + 60s video**, then let an algorithm pick the order. The session has no defined start or end — you scroll until you stop, exactly like a social feed.

## Strengths (per reviews)

- Extremely low barrier to entry — feels less intimidating than traditional prep.
- High retention from the social-feed UX + streaks.
- Free tier is genuinely full-featured.
- Authentic question bank ("official" College Board-style questions claimed).
- 100+ point score improvements reported in user reviews.

## Weaknesses / Caveats

- Format is great for *practice volume* but reviewers question whether passive swiping builds the deep conceptual mastery needed for a 1550+ score.
- Micro-learning works for habit but can fragment topics that need sustained focus (e.g., long Reading passages).
- UI bug: answer-choice text occasionally truncates on smaller screens.
- Monetization model unclear long-term despite "free forever" claim.
- Limited to SAT today; ACT/AP/desktop still roadmap.

## Relevance to APCSA Study Site

If applying this model to APCSA prep, the transferable mechanics would be:
1. **One-MCQ-per-card** vertical feed instead of paginated quizzes.
2. **Sub-60s explainer clips** per question (could be animated code walkthroughs).
3. **Spaced-repetition queue** that resurfaces missed topics across the 4 units.
4. **Streaks + leaderboards** for retention.
5. **No menu, instant-on** entry — bypass the home → unit → sub-unit flow for a "just give me a question" mode.

The current APCSA site uses a more traditional textbook structure (homepage → unit → sub-unit with MCQs at the end). A Dolphin-style "Practice Feed" mode could sit alongside it as an alternate entry point for casual sessions.
