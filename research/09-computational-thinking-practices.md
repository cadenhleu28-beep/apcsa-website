# Computational Thinking Practices — 2025-2026

The 2025-2026 CED removes "Big Ideas" entirely. The **5 Computational Thinking Practices (CTPs)** are the only cross-cutting framework remaining. All learning objectives map to one or more of these practices.

---

## The 5 Practices and Their Skills

### Practice 1 — Design Code
| Skill | Description |
|-------|-------------|
| 1.A | Determine an appropriate program design to solve a problem or accomplish a task |
| 1.B | Determine what knowledge can be extracted from data |

### Practice 2 — Develop Code
| Skill | Description |
|-------|-------------|
| 2.A | Write program code to implement an algorithm |
| 2.B | Write program code involving data abstractions (arrays, ArrayLists, objects) |
| 2.C | Write program code involving procedural abstractions (methods) |

### Practice 3 — Analyze Code
| Skill | Description |
|-------|-------------|
| 3.A | Determine the result or output of a program based on statement execution order |
| 3.B | Determine the result or output of code involving data abstractions |
| 3.C | Determine the result or output of code involving procedural abstractions |
| 3.D | Explain why code will not compile or work as intended, and modify to correct it |

### Practice 4 — Document Code and Computing Systems
| Skill | Description |
|-------|-------------|
| 4.A | Describe the behavior of a code segment or program |
| 4.B | Describe the initial conditions that must be met for a code segment to work as intended |

### Practice 5 — Use Computers Responsibly
| Skill | Description |
|-------|-------------|
| 5.A | Explain how computing impacts society, economy, and culture |

## MCQ Weighting by Practice

| Practice | Approximate MCQ Weight |
|----------|----------------------|
| Practice 1: Design Code | 2–10% |
| Practice 2: Develop Code | 22–38% |
| Practice 3: Analyze Code | 37–53% |
| Practice 4: Document Code | 10–15% |
| Practice 5: Use Responsibly | 2–10% |

**Key takeaway for students:** Practice 3 (Analyze Code) dominates the MCQ section at up to 53%. The majority of MCQ questions are "what does this code output?" or "what is wrong with this code?" — trace execution and find bugs.

---

## FRQ Practices Assessed

All 4 FRQ questions assess **Practice 2 (Develop Code)**. Skills 2.A, 2.B, and 2.C are all tested across the 4 questions.

| FRQ | Skills |
|-----|--------|
| Q1 (Methods & Control Structures) | 2.A, 2.C |
| Q2 (Class Design) | 2.B, 2.C |
| Q3 (ArrayList) | 2.A, 2.B |
| Q4 (2D Array) | 2.A, 2.B |

## Implications for Website Content

### MCQ questions on the site should weight toward:
1. **Code tracing** (Practice 3) — "What does this code print?" — ~40–50% of questions
2. **Writing code** (Practice 2) — "Which code correctly implements..." — ~25–35%
3. **Documentation** (Practice 4) — "What is the precondition?" — ~10–15%
4. **Design** (Practice 1) — "Which approach is correct?" — ~5–10%
5. **Ethics/Society** (Practice 5) — "Which is a concern?" — ~5%

### Concept Checks on the site should include:
- "What does this code print?" (Practice 3.A most common)
- "What is wrong with this code?" (Practice 3.D)
- "Which line causes a runtime exception?" (Practice 3.D)
- "What is the value of x after this loop?" (Practice 3.A)
- "What is the precondition for this method to work correctly?" (Practice 4.B)
